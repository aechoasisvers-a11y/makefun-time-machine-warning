A deadpan safety notice warning time travellers not to tamper with the past, because one ancestor is holding the whole timeline up.

## Entry

> WARNING: Do not alter the past. Your grandfather is a load-bearing ancestor.

## Run

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
